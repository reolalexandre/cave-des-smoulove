Stockage local sur cet appareil

Les cinq vins initiaux sont fictifs : supprime-les avant de saisir ton inventaire réel. Les modifications sont enregistrées sur cet appareil uniquement. Une sauvegarde JSON indépendante est indispensable : le navigateur peut effacer ses données. Pas de synchronisation ni de sauvegarde automatique en V1.

Une température de 18–22 °C peut accélérer le vieillissement : les échéances affichées sont des repères prudents, pas des garanties.
